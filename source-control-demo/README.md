# Source Control Demo — Thư viện sách

Website tĩnh đơn giản dùng HTML, CSS và JavaScript để thực hành Git và GitLab.

## Chạy website
Mở `index.html` bằng trình duyệt.

## Demo Source Control
1. `git init`
2. `git add .`
3. `git commit -m "Initial commit: create book library website"`
4. Tạo project trống trên GitLab.
5. Kết nối remote và push branch `main`.
6. Tạo branch `feature/add-book-category`, sửa code, commit và push.
7. Tạo Merge Request trên GitLab.

## Các file
- `index.html`: cấu trúc trang.
- `style.css`: giao diện.
- `script.js`: danh sách sách và tìm kiếm.
